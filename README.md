# تقرير مشروع نبض مدينتي (CityPulse AI)

## 1. مقدمة وفكرة المشروع
مشروع "نبض مدينتي" هو منصة ذكية متكاملة لإبلاغ ومتابعة مشاكل البنية التحتية والخدمات الحضرية (مثل الحفر في الشوارع، تلف أعمدة الإنارة، تراكم النفايات، وتكسر الأرصفة) في مدينة كركوك. يهدف المشروع إلى جسر الهوة بين المواطن والدوائر البلدية من خلال توظيف تقنيات الذكاء الاصطناعي لتصنيف الصور آلياً وتسريع الاستجابة الحكومية.

## 2. نظام العمل والهندسة البرمجية (System Architecture)
يعتمد النظام على تكامل تقنيات الويب والذكاء الاصطناعي وفق الآتي:
- واجهة المواطنين (index.html): تسمح للمواطنين بالتقاط صورة المشكلة، كتابة الوصف، وإرسال البلاغ بسهولة وتفاعلية.
- معالجة الذكاء الاصطناعي (FastAPI + YOLO): يستقبل الخادم (server.py) الصورة المرفوعة ويمررها لنموذج YOLO عبر ملف (best.pt) لتحديد نوع المشكلة وتصنيفها بدقة.
- التخزين الآمن (reports.db): قاعدة بيانات SQLite محلية لتخزين تفاصيل البلاغات، الصور، التواريخ، وحالات المعالجة.
- لوحة التحكم الحكومية (government.html): واجهة مخصصة للجهات المسؤولة والبلدية لمتابعة البلاغات الواردة، فرزها، وتغيير حالتها (قيد المعالجة، تم الحل).

## 3. محتويات المشروع والملفات البرمجية
- server.py: الخادم الرئيسي المبني بإطار العمل FastAPI لإدارة المسارات، معالجة الصور، وتشغيل نموذج الذكاء الاصطناعي وقاعدة البيانات.
- index.html: واجهة المستخدم التفاعلية لتقديم البلاغات من قبل المواطنين.
- government.html: لوحة تحكم الجهات البلدية والحكومية لمتابعة وإدارة البلاغات.
- best.pt: نموذج YOLO المدرب خصيصاً للتعرف على عيوب البنية التحتية.
- reports.db: قاعدة بيانات SQLite لتخزين سجلات البلاغات والبيانات الوصفية.
- requirements.txt: ملف متطلبات الحزم والمكتبات البرمجية (FastAPI, Uvicorn, Ultralytics, OpenCV وغيرها).

## 4. التقنيات المستخدمة (Tech Stack)
- Backend: Python, FastAPI, Uvicorn
- AI & Computer Vision: Ultralytics YOLO, OpenCV, NumPy
- Database: SQLite
- Frontend: HTML5, CSS3, JavaScript

## 5. طريقة التثبيت والتشغيل
1. فتح مجلد المشروع عبر الطرفية (Terminal).
2. تثبيت الحزم والمكتبات المطلوبة عبر الأمر:
   pip install -r requirements.txt
3. تشغيل الخادم المحلي عبر الأمر:
   uvicorn server:app --reload
4. الوصول للمنصة عبر المتصفح:
   - واجهة المواطنين: http://127.0.0.1:8000/index.html
   - لوحة التحكم الحكومية: http://127.0.0.1:8000/government.html
